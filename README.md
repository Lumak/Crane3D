Crane3D Game Engine is a renamed repo of Urho3D game engine, tag 1.7.1. The original Urho3D repository has been abandoned and archived since Jan. 2023 but will continue as Crane3D game engine starting from tag 1.7.1, which was the last stable release that I was familiar with. Urho3D's credits and its history can be found in the Urho3D_Original_Readme.md file.
